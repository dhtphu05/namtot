# 5TOT Đà Nẵng — Backend ↔ UI Contract Matrix

> Audit snapshot: 2026-09-29 worktrees. The current source and tests are the behavioral reference. Items marked **WIP** are present only in uncommitted worktree changes and are not stable contract. This matrix is a product/UI contract; it does not change API or infer missing backend behavior.

## Global contract

| Concern | Verified contract | Source of truth |
|---|---|---|
| Workspace types | `CITY`, `UNIVERSITY_SYSTEM`, `SCHOOL`. A School parent is nullable; if present it must be an active University System. No other hierarchy is supported. | `sv5tot-backend/prisma/schema.prisma`; `src/modules/workspaces/workspaces.service.ts`; admin workspace tests |
| Roles | `student`, `class_representative`, `officer`, `manager`, `committee`, `admin`, `data_uploader`, `city_officer`, `city_manager`, `city_committee`. Six target roles do not erase four legacy roles. | schema; `namtot/src/features/auth/role-map.ts` |
| Criterion | Canonical City review tasks are exactly `ethics`, `academic`, `physical`, `volunteer`, `integration`. Backend also retains `priority` and `collective` as legacy/additional criterion enums; neither creates a sixth City task. | schema; `src/modules/applications/applications.service.ts:createReviewTasksForSubmit`; `tests/unit/review-ensure-tasks.test.ts` |
| Level | Legacy enum retains `school`, `university`, `city`, `central`; City-only target IA must not expose target-level selection/cascade. | schema; `namtot/src/lib/levels.ts`; application/manager UI |
| Application state | `not_started`, `draft`, `prechecked`, `ready_to_submit`, `submitted`, `supplement_required`, `under_review`, `resolution_needed`, `completed`, `rejected`. There is no `cancelled` or `archived` status. | schema `ApplicationStatus`; lifecycle fields and manager services |
| Lifecycle overlay | Cancellation/archive are timestamps and metadata over an application; final decision history preserves superseded official result. Reopen can restore operational state and unarchive. | schema (`cancelledAt`, `archivedAt`, `ApplicationFinalDecisionHistory`); `src/modules/manager/manager.service.ts`; lifecycle tests |
| Error envelope | API errors use `{success:false,error:{code,message,details,...},meta:{requestId}}`; stack is non-production only. UI must map code to action and never expose raw DB/provider detail. | backend error middleware; `namtot/src/lib/api/client.ts` |
| Tenant boundary | City review scope permits City workspace resources and active School records for review; Admin global; legacy staff stay within their workspace. This is not universal cross-school access for unrelated modules. | `src/shared/utils/review-workspace-scope.ts:reviewWorkspaceFilterFor/assertReviewWorkspaceAccess`; module-specific guards |
| Source integrity | AI, OCR, and rules are advisory/processing outputs. Eligibility and final decisions are server results; human finalization is a distinct action. | applications/review/manager services and tests |
