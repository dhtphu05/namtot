# Student Application UI V2 Design Inventory

Phase 0.5 inventory for translating the mandatory visual contract into repository-native aliases and primitives. This is an internal mapping only; it does not authorize page redesign outside the V2 rollout flag.

| Mandatory visual token/pattern | Existing repository token/component                                                                  | V2 direction                                                                                                                  |
| ------------------------------ | ---------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| Institutional navy `#123B6D`   | No exact legacy token; current brand uses `--brand-primary` / `--brand-deep`                         | Extend as `--student-v2-institutional-navy` for lockup and major headings                                                     |
| Institutional blue `#0057C2`   | `--brand-primary` and many legacy hardcoded `#0057C2` uses                                           | Reuse via alias `--student-v2-institutional-blue`; new V2 feature code should use the alias                                   |
| Institutional cyan `#0796D2`   | No stable semantic token                                                                             | Extend as restrained accent alias only                                                                                        |
| App/page surfaces              | `--surface-app`, `--surface-primary`, `--surface-secondary`, `--surface-muted`, `--surface-selected` | Extend with exact V2 aliases so legacy surface values remain unchanged                                                        |
| Divider / borders              | `--border`, `border-slate-*`, `border-[#E3ECF6]`                                                     | Extend `--student-v2-divider`, `--student-v2-border-default`, `--student-v2-border-strong`                                    |
| Focus ring                     | `--ring`, `focus-visible:ring-ring/25`, hardcoded blue focus                                         | Extend `--student-v2-focus-ring`; reuse visible focus utilities in V2 primitives                                              |
| Four progress statuses         | `StatusBadge` tone model: good/warning/danger/neutral/info                                           | Extend `StatusPillV2` with complete/waiting/supplement/not-started only                                                       |
| Critical red                   | `--danger`, `--surface-danger`, rose utility classes                                                 | Extend `--student-v2-critical-text` and `--student-v2-critical-bg`; use only for error/rejection/destructive/critical overdue |
| Control radius 8px             | `--radius`, `rounded-md`, `AppButton` rounded-xl                                                     | Reuse `--radius` concept but expose `--student-v2-radius-control: 8px`                                                        |
| Section radius 10-12px         | `Card` rounded-xl, `SectionCard` rounded-2xl                                                         | Extend `--student-v2-radius-section: 12px`; V2 normal sections avoid rounded-2xl                                              |
| Overlay radius/elevation       | Dialog/sheet/popover use Radix/shadcn shadows                                                        | Extend `--student-v2-radius-overlay` and `--student-v2-elevation-overlay`; reuse existing Sheet/Dialog mechanics              |
| No normal section shadow       | `Card` and `SectionCard` include subtle shadows                                                      | Deprecate shadowed section cards for V2 page sections; keep legacy unchanged                                                  |
| Buttons                        | `Button` in `src/components/ui/button.tsx`, `AppButton` in student primitives                        | Extend `ButtonV2` with primary/secondary/tertiary/destructive semantic variants                                               |
| Tables                         | `src/components/ui/table.tsx` compact table primitives                                               | Reuse table behavior; add `DefinitionTableV2` for requirement data                                                            |
| Criteria navigation            | Legacy criterion cards/buttons inside application workspace                                          | Extend `CriteriaNavigationRowV2` and `FiveCriteriaSpineV2`; no criterion-specific colors                                      |
| Evidence cards/previews        | `StudentEvidenceCard` uses compact legacy card and image preview                                     | Extend `EvidenceCardV2`; document previews use contain, photo previews use cover, official data uses tile                     |
| Empty/error states             | `EmptyState`, `InlineAlert` in student primitives                                                    | Extend `CompactEmptyStateV2`, `InlineErrorStateV2`, `CriticalStateV2`; keep compact and non-illustrative                      |
| Student shell/sidebar          | `StudentAppShell`, `Sidebar`, `UserWorkspaceInfo`                                                    | Reuse shell; future V2 shell work should only adjust internals under rollout guard                                            |
| Typography                     | Global Be Vietnam Pro; mixed Tailwind sizes                                                          | Reuse font; V2 primitives expose the mandatory hierarchy in component classes                                                 |
