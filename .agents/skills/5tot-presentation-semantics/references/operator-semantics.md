# Operator Semantics

Use operator labels as business explanations, not raw formulas.

## `all_of`

Meaning: every required condition in the group must be satisfied.

Student copy: `Cần đủ các điều kiện bắt buộc`.

## `one_of`

Meaning: one valid path is enough.

Student copy: `Chỉ cần chọn một cách chứng minh phù hợp`.

Do not show `0/4`, `1/5`, or any denominator that looks like all choices are required.

## `at_least_n`

Meaning: satisfy at least the configured required count.

Student copy: `Cần đạt ít nhất N điều kiện`.

Use the required count as the target, not the total option count.

## `activity_aggregation`

Meaning: totals come from verified activity entries. Pending declared values are not official completion.

Student copy: `Tổng đã xác nhận`, `Chờ xác minh`, and `Mục tiêu`.

## Optional Groups

Optional groups must not block school-level completion unless the active criteria version says they are required.

Student copy: `Không bắt buộc ở cấp hiện tại`.
